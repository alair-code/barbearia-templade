# barbearia-templade

Template comercial reutilizável para barbearias, construído com HTML5, CSS3 e JavaScript puro.

## Estrutura
- index.html — estrutura da página
- css/style.css — identidade visual e responsividade
- js/script.js — configurações e interações
- assets/ — espaço para imagens, ícones e logo

## Personalização rápida
A configuração principal está no início de js/script.js, no objeto CONFIG.
Troque nome, slogan, WhatsApp, telefone, Instagram, endereço, serviços e horários.
As cores principais ficam nas variáveis CSS no início de css/style.css.

## Executar
Abra index.html em um navegador ou use qualquer servidor HTTP local.
